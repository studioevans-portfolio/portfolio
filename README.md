# Studio Evans Website

The official website for Studio Evans, a creative design studio specialising in graphic design, branding and web design.

Overview

A custom-built, responsive website designed and developed from the ground up with a focus on clean design, usability and performance across desktop and mobile devices.

Built With

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* GitHub Pages

Features

* Fully responsive layout
* Custom-designed interface
* Mobile-optimised navigation and layouts
* Custom domain configuration
* SEO and search engine indexing
* Mobile Home Screen / app-style icon support

Development

The website was developed with the assistance of AI tools alongside hands-on development, testing and extensive code refinement.

The project was built and refined over a short development period, with particular attention given to responsive behaviour, visual consistency and the overall user experience.
